1️⃣ Money Transfer App

Tech Stack: Angular, Node.js, Sequelize, PostgreSQL, Firebase

🔹 Overview:

The Money Transfer App allows users to send money securely worldwide. It includes real-time tracking and compliance verification.

🔹 Challenges & Solutions:

  • Challenge: Ensuring real-time updates for transactions.
  • Solution: Used Firebase Firestore for real-time notifications.
  • Challenge: Securing sensitive financial data.
  • Solution: Implemented JWT and API key authentication.

function generateToken(user) {
